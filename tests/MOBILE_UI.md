# 移动端界面与验收

移动端默认进入音乐首页，保留系统状态栏的安全区，不绘制虚假的时间、电量或底部导航。桌面端继续使用原有导航与布局。手动验证登录入口已移除，会话恢复、后台刷新、过期后的登录流程仍由认证模块处理。

首页由搜索框、横向电台卡、真实账号收藏列表组成。电台卡与收藏在同一滚动容器内，上滚时卡片退出视口并收起，下滚恢复；搜索框和播放胶囊保持固定。胶囊仅在存在当前歌曲时显示，列表底部留足可滚动空间。歌曲更多菜单提供立即播放和下一首播放，不隐式替换当前队列；播放全部使用现有收藏来源。所有播放操作（电台、播放全部、歌曲选择、队列选歌、上下首）都保留当前页面，队列选歌也不自动关闭队列；仅显式点击胶囊左侧等导航操作才进入播放页。

首页搜索并行查询歌手与歌曲。歌手横向卡片在前，歌曲列表在后；中文输入法合成期间不发请求，修改查询取消旧请求，分页仍归目录控制器管理。点击歌手进入其专辑页。播放页暂停浏览时保留首页输入与滚动位置；返回首页不聚焦搜索框，不弹出输入法。

两个电台卡片分别预载各自首批歌曲，以第一首歌曲的封面作为卡面；点击播放复用同一批歌曲，避免展示封面与实际首曲不符。预载不改变当前播放，失败可在点击时重试；切换账号或停止应用会清理缓存并取消请求。当前电台播放时仅显示跳动音量条，保持圆形控件，不显示状态文字；点击可暂停，再点继续当前歌曲，暂停或切换到其他来源时恢复播放图标。电台内切换歌曲不改变首曲封面。

`ArtworkBackground` 是唯一封面采样入口，始终跟随当前播放歌曲；预览相邻封面不改变背景。色彩经本地图片代理采样，缓存限制为 100 份。采样失败使用默认氛围色；背景光斑与遮罩不接收触摸事件。

胶囊左侧打开播放页，由真实封面元素通过 Web Animations 在两个位置之间移动、缩放并改变圆角，结束时不替换图片。完整过渡为 1000ms，松手续接按剩余距离计算时长且不短于 240ms；拖动阶段仍即时跟随手指。移动缩放使用持续保留的外层合成图层，圆角与左右预览透视保留在内层，避免过渡中覆盖透视矩阵或在二维、三维变换之间切换；封面图片使用同步解码提示。播放页不显示顶部横条，保留左右立体封面预览和预览歌曲名称。封面下滑时即时向首页胶囊位置移动缩小，并逐步显露首页；拖动超过 80px 后松手完成剩余路径，否则沿当前路径复位。取消手势、改变曲目、窗口缩放和卸载会清理临时动画样式。预览曲目下滑时渐变到正在播放的封面，不触发播放。歌词、转盘操作保持可用。系统返回键从播放页或二级页面返回首页，首页返回键交给 Android 最小化。减少动态效果设置会关闭背景漂移和共享封面动画。

验证命令：`pnpm check`、`pnpm test`。`tests/react-ui.test.js` 覆盖首页操作、搜索、队列、手势与会话流程；`tests/catalog-layout.test.js` 在 Chromium 下验证 320×568、390×844、430×932 的布局、毛玻璃叠层、滚动、封面正反向过渡、动态取色及卸载清理。过渡测试加载真实图片，采样 61 个时间点检查图片可见性、连续位移和内层透视稳定性，并覆盖开启动画被下滑打断时的位置连续性。测试使用隔离的模拟账号与歌曲，不访问真实 QQ 账号。Android 真机仍需检查系统安全区、WebView 动画流畅度及后台恢复。
