# Third-party components

qmplay embeds a selected subset of [Rain120/qq-music-api](https://github.com/Rain120/qq-music-api), version 2.0.0, including the current local QR authentication and favorites extensions. The source snapshot was imported from the adjacent checkout based on commit `d05420bf098bd2769866eba81cfd48a6d0c6f50c`, including its local changes on 2026-10-25. Only the application's music, artist, radio, lyric, authentication and favorites endpoints and their dependencies are included under `backend/`.

The upstream project identifies Rain120 as its author and states `Copyright © 2019-present Rain120` in its README. Its original MIT license is preserved verbatim in `licenses/qq-music-api.LICENSE`. Adaptations retain the existing controller, service and utility separation.

The imported upstream README also states: `当前代码仅供学习，不可做商业用途。` This notice is retained as provenance; embedding the code does not resolve the difference between that statement and the upstream MIT license, or grant rights to QQ Music's service, music, artwork or trademarks.

During each backend build, licenses of the actual bundled npm packages are collected in `dist/backend/THIRD_PARTY_NOTICES.txt`, with a dependency inventory in `dist/backend/dependencies.json`. Backend dependencies are build dependencies because their code is included in the JavaScript bundle; a separate runtime `node_modules` tree is not needed.

Electron's own `LICENSE` and `LICENSES.chromium.html` remain in the distribution generated by electron-builder. The placeholder cover (`assets/coast.jpg`) was generated with the image generation tool; `assets/icon.svg` and `assets/icon.png` are project-created icons.

This file identifies third-party components and does not assign a new license or copyright owner to qmplay's original code.

Android packages embed [Node.js Mobile 18.20.4](https://github.com/nodejs-mobile/nodejs-mobile/releases/tag/v18.20.4) and the Android NDK's LLVM libc++ shared runtime. The complete Node.js license and bundled backend notices are packaged in the application's `assets/runtime.zip` under `web/assets/NODE_LICENSE.txt` and `web/assets/THIRD_PARTY_NOTICES.txt`. The NDK libc++ license is retained at `web/assets/LIBCXX_LICENSE.txt`. These components do not replace the upstream notices above.
