# qmplay

面向 Linux 的极简 QQ 音乐播放器。

## 功能

- 公共电台, 个性电台
- 歌手搜索
- 音乐收藏

## 运行

需要 Node.js 22.12+ 和 pnpm 11.25.0。

```sh
pnpm install --frozen-lockfile
pnpm build
pnpm start
```
